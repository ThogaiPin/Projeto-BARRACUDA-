# 🐟 Projeto BARRACUDA

## Chatbot para Doações

Projeto de Extensão — Análise e Desenvolvimento de Sistemas

---

## 📌 Sobre o Projeto

O **Projeto BARRACUDA** é uma aplicação desenvolvida em **Java** com o objetivo de facilitar e humanizar o processo de doações por meio de um chatbot com Inteligência Artificial.

A proposta é permitir que pessoas que possuem objetos ou itens que não utilizam mais possam realizar uma doação de maneira simples, rápida e acessível através do celular.

Entre os itens que podem ser doados estão:

- Sofás
- Estantes
- Roupas
- Brinquedos
- Móveis
- Outros itens em boas condições de uso

O projeto busca utilizar a tecnologia para aproximar quem deseja doar de quem pode receber a doação, tornando o processo mais organizado e acessível.

## ❗ Problema Real

O processo de doação pode ser burocrático e pouco acessível para algumas pessoas.

Uma pessoa pode possuir um sofá, uma estante, roupas, brinquedos ou outros objetos que não utiliza mais, mas pode encontrar dificuldades para realizar essa doação.

Entre essas dificuldades estão:

- Encontrar alguém ou uma instituição interessada;
- Entrar em contato;
- Informar os dados da doação;
- Combinar uma data;
- Informar o endereço para coleta;
- Organizar o transporte do item.

Pensando nisso, o BARRACUDA propõe colocar esse processo dentro do celular do usuário, permitindo que ele realize sua doação através de uma conversa com um chatbot.

---

## 💡 Solução com Inteligência Artificial

A solução proposta pelo Projeto BARRACUDA é um chatbot com **Inteligência Artificial**, desenvolvido utilizando **Java**.

Ao entrar na aplicação, o usuário não precisará preencher diversos formulários.

Em vez disso, poderá conversar diretamente com o chatbot e informar as informações necessárias de maneira natural.

Por exemplo:

    BARRACUDA: Olá! O que você gostaria de doar?

    Usuário: Quero doar um sofá.

    BARRACUDA: Perfeito! Qual é o endereço para a coleta?

    Usuário: Rua das Flores, 100.

    BARRACUDA: Qual data você gostaria que a coleta fosse realizada?

    Usuário: Dia 15.

    BARRACUDA: Certo! Vou confirmar os dados da sua doação.

    Item: Sofá
    Endereço: Rua das Flores, 100
    Data: Dia 15

    BARRACUDA: Os dados estão corretos?

    Usuário: Sim.

    BARRACUDA: Doação registrada com sucesso!

A Inteligência Artificial será responsável por interpretar a conversa e identificar as informações importantes fornecidas pelo usuário.

## ☕ Tecnologia Principal

### Java

O projeto será desenvolvido principalmente utilizando a linguagem **Java**.

O Java será utilizado para:

- Desenvolvimento da aplicação;
- Implementação da lógica do sistema;
- Processamento das informações;
- Gerenciamento das doações;
- Organização dos dados;
- Funcionamento das regras do chatbot;
- Integração com os recursos de Inteligência Artificial.

---

## 🤖 Inteligência Artificial

A Inteligência Artificial será utilizada para tornar a interação entre o usuário e o sistema mais natural.

O chatbot deverá ser capaz de:

1. Iniciar uma conversa com o usuário;
2. Identificar que o usuário deseja realizar uma doação;
3. Identificar o item que será doado;
4. Solicitar as informações necessárias;
5. Identificar informações fornecidas durante a conversa;
6. Solicitar informações que estejam faltando;
7. Organizar os dados da doação;
8. Confirmar os dados com o usuário;
9. Registrar a solicitação.

## 👥 Público-Alvo

O público-alvo do Projeto BARRACUDA são principalmente **adultos que possuem objetos ou itens que desejam doar**.

Entre os possíveis usuários estão pessoas que:

- Possuem objetos que não utilizam mais;
- Desejam ajudar outras pessoas através de doações;
- Possuem móveis, roupas, brinquedos ou outros itens;
- Procuram uma maneira simples de realizar uma doação;
- Não querem passar por processos burocráticos.

Futuramente, o sistema também poderá atender instituições e organizações responsáveis pelo recebimento e distribuição das doações.
